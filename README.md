# theHunter: Call of the Wild — AI 자동 번역 패치

게임의 영어 원문을 AI로 한국어로 번역한 비공식 무료 패치입니다. 기본 게임과 DLC의 메뉴, 장비·동물 설명, 임무, 대사 자막을 한국어로 표시합니다.

**[최신 패치 다운로드](https://github.com/fullmetalsonic/thehunter-cotw-korean-ai/releases/latest)**

## 지원 환경

- Windows 10/11, Steam판
- Steam 빌드 `26051119` / `code_final 3366163` / `archives 3322479`
- 게임 언어: **English**

지원 버전과 다른 게임에는 자동 적용하지 않습니다. Epic판은 이번 배포의 지원 대상에 포함하지 않았습니다. Python을 별도로 설치할 필요는 없습니다.

## 적용

1. 게임을 완전히 종료합니다.
2. 다운로드한 ZIP을 **폴더 전체로 압축 해제**합니다. EXE와 `payload` 폴더를 함께 두세요.
3. `AI 자동 번역 패치.exe`를 실행합니다. 자동으로 찾은 게임 폴더를 확인하거나 **폴더 선택**으로 지정합니다.
4. **패치 적용**을 누릅니다. 기존 파일이 있으면 먼저 백업하고 패치 파일을 복사·검증합니다.
5. Steam의 게임 **속성**에서 언어를 **English**로 설정합니다.
6. 게임 속성의 **시작 옵션**에 다음 줄을 입력합니다. 패처의 **옵션 복사** 버튼으로 복사할 수 있습니다. 마지막 마침표도 포함하세요.

```text
--vfs-fs dropzone --vfs-archive archives_win64 --vfs-archive patch_win64 --vfs-archive dlc_win64 --vfs-fs .
```

7. Steam에서 게임을 실행합니다.

언어와 시작 옵션은 처음 한 번 설정하면 됩니다. 기존 시작 옵션은 먼저 따로 보관하세요. 이미 `--vfs-` 옵션이 있다면 같은 옵션을 중복으로 덧붙이지 말고 위 구성과 대조하세요. 패처는 Steam 설정 파일을 직접 편집하지 않습니다.

게임 폴더는 Steam 라이브러리에서 게임을 우클릭한 뒤 **관리 → 로컬 파일 탐색**으로도 찾을 수 있습니다. 쓰기 권한 오류가 나면 패처를 닫고 관리자 권한으로 다시 실행하세요.

## 복원

게임을 종료한 뒤 같은 패처에서 **이전 상태 복원**을 누릅니다.

최초 적용 직전의 두 파일 상태를 복원합니다. 기존 한글 패치가 있었다면 그 패치로 돌아갑니다. 원래 없던 파일은 이 패처가 설치한 내용과 일치할 때만 제거합니다. 적용 후 사용자가 수정한 파일이 발견되면 자동 덮어쓰기를 중단합니다.

백업은 게임 폴더의 `.ai-korean-patch-v1-backup`에 보관합니다. 복원 후에도 백업은 유지되므로 삭제하지 마세요. 다른 `dropzone` 파일은 보존합니다. Steam 언어·시작 옵션은 필요에 따라 직접 이전 값으로 되돌리세요.

## 새 버전 적용

기존 버전의 패처로 **이전 상태 복원**을 먼저 실행하고, 새 ZIP을 별도 폴더에 풀어 새 패처로 적용하세요. 최초 백업을 덮어쓰지 않습니다.

패처는 시작할 때 최신 정식 Release를 비차단 방식으로 확인하며 **업데이트 확인** 버튼도 제공합니다. 현재 버전과 최신 버전, 업데이트 필요 여부와 Release 링크를 표시합니다. 자동 설치하지 않으며 인터넷 연결 실패도 로컬 적용·복원을 막지 않습니다.

## 번역과 폰트

이 공개판의 번역 입력은 해당 게임 빌드에서 추출한 영어 원문과 문자열 ID입니다. 문맥에 맞춰 번역하고 변수, 키 입력 표시, 태그, 수치와 문자열 구조를 검사합니다. 총 대상은 22,079개 문자열입니다. v1.0.2에서는 메뉴·설정·인벤토리·트로피·사냥개 관리와 연결된 설명의 UI 용어를 재검토했습니다. 학명·제품명·기술 약어·일부 고유 지명은 원문 표기를 유지합니다. 온라인 뉴스나 홍보 이미지 안의 글자는 이 문자열 패치의 범위에 포함되지 않습니다.

배포용 글꼴은 Noto Sans KR 및 Noto Sans로 구성했습니다. 글꼴 저작권 고지와 SIL Open Font License는 `licenses` 폴더에 포함되어 있습니다.

AI 번역의 어색한 표현이나 오역을 발견하면 [이슈](https://github.com/fullmetalsonic/thehunter-cotw-korean-ai/issues)에 게임 버전과 해당 문구를 남겨 주세요.

## 권리 고지

theHunter: Call of the Wild와 원작 게임 자료의 권리는 해당 권리자에게 있습니다. 이 프로젝트는 게임 제작사·배급사의 공식 패치가 아닙니다. 폰트의 이용·수정·재배포에는 동봉한 OFL 조건이 적용됩니다.

## 검증 범위

22,079개 문자열의 ID·변수·태그·줄바꿈과 리소스 구조를 검사했습니다. 패처는 임시 게임 폴더에서 적용·복원 및 오류 시 복구를 시험했고, 실제 배포 파일의 복사 후 해시와 복원도 확인했습니다.

v1.0.0은 기존 패치를 제외한 공개판 리소스만으로 실행하여 메인 화면의 한글과 새 폰트를 확인했습니다. v1.0.2는 같은 폰트를 사용하며 UI와 연결 안내 526개를 교정했고, 새 버전의 화면 재검증은 하지 않았습니다. Esc 메뉴·인벤토리 및 공개판만 사용한 게임 내 HUD는 추가 화면 확인을 마치지 못했습니다. 대사 전체를 실제 플레이로 검증한 것은 아닙니다. 상세 결과는 GitHub 저장소의 `validation` 폴더에 있습니다.
