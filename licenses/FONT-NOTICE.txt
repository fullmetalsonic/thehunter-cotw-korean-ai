- 모든 DefineFont3 자형 윤곽을 위 두 OFL 폰트에서 다시 생성했습니다.

검증 범위

영어 전체를 신규 번역한 최종 문구 22,079행의 가시 문자 1,516종과 한글 1,404종을 대조했습니다.
본문 font ID 1은 가시 문자 1,516종 모두 누락 0입니다.
두 폰트 모두 한글 1,404종의 누락은 0입니다.
제목 font ID 2는 원래 코드맵에 없는 °(U+00B0), ²(U+00B2) 두 기호가 누락됩니다.
기존 glyph index 보존을 위해 이 두 기호를 추가하지 않았습니다.
DefineFont3는 CodeTable의 오름차순 정렬을 요구하므로 올바르게 삽입하려면
기존 자형 11,381개의 index를 바꾸어야 합니다. 끝에 붙이는 방법은 정렬 규약을 위반합니다.
정확한 최종 커버 결과는 GitHub 저장소의 validation/font-coverage.json에 있으며,
소스/산출물 해시와 구조 검증 및 코드맵 보존 결정은 validation/font-build.json에 있습니다.
최종 문구 SHA-256: 9cc148f42457bddf668bea41b8d91e645373b75214035190dfd99b2f5d8eb404
기존 패치를 제외하고 공개판 리소스만 사용하는 별도 상대 경로로 실행하여
v1.0.0 메인 화면의 한글과 새 폰트를 확인했습니다.
v1.0.1은 문구 6행만 교정했으며 같은 폰트를 사용합니다. 새 버전의 화면 재검증은 하지 않았습니다. 공개판만 사용한 게임 내 HUD는 미확인입니다.
Esc 메뉴·인벤토리와 제목용 두 기호의 실제 fallback은 추가 화면 검증을 마치지 못했습니다.
